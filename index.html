Architecture Overview

The 7-Stage Compilation Pipeline

Algo-C translates high-level algorithmic expressions into native execution through seven rigorous phases.

Phase 1

Lexical Analysis (Lexer)

Scans input source stream, strips comments and whitespace, and categorizes characters into structured lexical tokens with line and column tracking.

Finite Automata Multi-Char Ops Source Loc
Phase 2

Syntax Analysis (Parser)

Uses recursive descent parsing with operator precedence climbing to construct an unambiguous parse tree according to Context-Free Grammar.

Precedence Climbing CFG Grammar Error Recovery
Phase 3

Abstract Syntax Tree (AST)

Emits hierarchical, typed LLVM-style RTTI nodes representing Functions, Prototypes, Blocks, Statements, Arrays, and Expressions.

LLVM RTTI std::unique_ptr Visitor Pattern
Phase 4

Semantic Analyzer & SymTab

Maintains multi-level lexical scopes, enforces strict type compatibility, verifies array bounds, and conducts definite-return path analysis.

Scoped SymTab Type Safety Definite Returns
Phase 5

Optimization Engine (-O1)

Applies compile-time constant folding, algebraic simplification (x*1=x, x+0=x, x*0=0), and dead branch elimination.

Constant Folding Algebraic Identities Dead Code Elimination
Phase 6

LLVM IR & Target CodeGen

Generates SSA-compliant LLVM Intermediate Representation and emits AMD64 / x86-64 target assembly code adhering to calling conventions.

LLVM IR 18+ x86-64 Gas ABI Prologue/Epilogue
Phase 7

Virtual Machine Interpreter

Executes compiled bytecode or AST directly in a stack-based runtime environment with built-in standard I/O library support.

Stack VM Runtime IO Instant Execution
Reference Manual

Algo-C Language Specification

Grammar syntax, supported primitive types, composite structures, and built-in standard library functions.

Primitive & Array Types

Algo-C is strongly typed with static type safety enforced at compile time:

  • int : 32-bit signed integer
  • float : 64-bit IEEE 754 floating-point value
  • bool : Boolean logic (true / false)
  • void : Empty type used for procedures with no return value
  • int arr[N] : Fixed-size contiguous integer array

Control Flow Constructs

C-like algorithmic control structures with nested scope support:

  • if (condition) { ... } else { ... }
  • while (condition) { ... }
  • return expression;
  • Block scoping with local variable shadowing

Standard I/O Builtins

Built-in runtime procedures linked during IR/VM execution:

  • print_int(int val) : Prints integer to stdout
  • print_str(string text) : Prints string literal
  • println() : Emits a newline character
  • print_bool(bool val) : Prints true or false
  • read_int() : Reads integer from stdin

Local Development

CLI Flags & Build Guide

How to clone, compile, and run Algo-C natively on Windows, Linux, or macOS.

# 1. Clone the repository
git clone https://github.com/NeerajRoy24/Algo-C-Compiler.git
cd Algo-C-Compiler

# 2. Build via GCC / Clang (C++17) or batch script
.\build.bat # On Windows
# OR using CMake:
mkdir build && cd build && cmake .. && cmake --build .

# 3. Compiler Command-Line Options
.\algoc.exe --run tests\test1_gcd.algoc # Run algorithm directly via VM
.\algoc.exe --emit-llvm tests\test1_gcd.algoc # Emit authentic LLVM IR
.\algoc.exe --emit-asm tests\test1_gcd.algoc # Emit x86-64 assembly
.\algoc.exe --optimize tests\test6_optimization.algoc # Run optimization passes
.\algoc.exe --dump-symtab tests\test1_gcd.algoc # Print scoped symbol table
.\algoc.exe --dump-ast tests\test1_gcd.algoc # Dump AST node tree
.\algoc.exe --dump-tokens tests\test1_gcd.algoc # Dump token stream
